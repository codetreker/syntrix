# Instance PostgreSQL Database Catalog Schema

**Status:** Current catalog schema; project-aware ownership remains accepted design work.
**Scope:** System metadata for logical Syntrix databases inside one runtime instance.

## 1. Ownership and Current Schema

The [platform architecture](../../../../architecture.md) gives each developer
one or more runtime instances, each with Syntrix services, MongoDB, and a
private PostgreSQL system database. Projects, project end-user accounts,
OAuth state, and logical database configuration belong to that instance.
Business documents belong to logical Syntrix databases backed by MongoDB.
The PostgreSQL database is not a developer-facing Syntrix database.

Console owns developer accounts and instance management entry points.
Management owns employee-facing platform coordination. Neither is the storage
owner for instance projects, end users, OAuth configuration, or this catalog.
Instance Identity handles end-user authentication; catalog lifecycle is a
separate local responsibility.

The current `databases` table already exists. It stores metadata but has no
project column. Its `owner_id` represents the current instance user model,
not a Console developer account, project identity, or Management employee.
The current factory uses the same PostgreSQL connection for `auth_users` and
`databases`. Project scoping requires an explicit schema/API migration; this
document does not introduce that migration or foreign keys.

The source owners are
[the catalog store](../../../../../packages/syntrix/internal/core/database/postgres/store.go)
and [the SQL definition](../../../../../packages/syntrix/internal/core/storage/postgres/migrations/002_create_databases.sql).
The DDL below records the present shape. Query examples explain the catalog
operations; timestamps and returned values are populated by the current Go
store rather than an assumed project-aware API.

## 2. Table Definition

```sql
CREATE TABLE databases (
    -- Primary identifier (auto-generated: hex(blake3(uuid())[:8]))
    id VARCHAR(16) PRIMARY KEY,

    -- URL-friendly identifier (optional, user-defined, immutable once set)
    slug VARCHAR(63) UNIQUE,

    -- Display information
    display_name VARCHAR(255) NOT NULL,
    description TEXT,

    -- Ownership (matches auth_users.id type: VARCHAR(64))
    -- Current owner is an instance user ID; no project binding exists yet
    owner_id VARCHAR(64) NOT NULL,

    -- Timestamps
    created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW(),

    -- Quota settings (0 = unlimited)
    max_documents BIGINT NOT NULL DEFAULT 0,
    max_storage_bytes BIGINT NOT NULL DEFAULT 0,

    -- Status
    status VARCHAR(20) NOT NULL DEFAULT 'active',

    -- Constraints
    CONSTRAINT chk_databases_id CHECK (
        id ~ '^[0-9a-f]{16}$'
    ),
    CONSTRAINT chk_databases_slug CHECK (
        slug IS NULL OR slug ~ '^[a-z][a-z0-9-]{2,62}$'
    ),
    CONSTRAINT chk_databases_status CHECK (
        status IN ('active', 'suspended', 'deleting')
    ),
    CONSTRAINT chk_databases_max_documents CHECK (max_documents >= 0),
    CONSTRAINT chk_databases_max_storage CHECK (max_storage_bytes >= 0)
);

-- Performance indexes
CREATE INDEX idx_databases_owner ON databases(owner_id);
CREATE INDEX idx_databases_status ON databases(status);
CREATE INDEX idx_databases_created_at ON databases(created_at DESC);
CREATE INDEX idx_databases_slug ON databases(slug) WHERE slug IS NOT NULL;

-- Composite index for common queries
CREATE INDEX idx_databases_owner_status ON databases(owner_id, status);
```

| Column | Type | Nullable | Default | Description |
|--------|------|----------|---------|-------------|

| `display_name` | VARCHAR(255) | NO | - | Human-readable name |
| `description` | TEXT | YES | NULL | Optional description |
| `owner_id` | VARCHAR(64) | NO | - | Current instance user owner ID; no project or Console identity mapping |

| `updated_at` | TIMESTAMPTZ | NO | NOW() | Last update timestamp |
| `max_documents` | BIGINT | NO | 0 | Document limit (0=unlimited) |
| `max_storage_bytes` | BIGINT | NO | 0 | Storage limit (0=unlimited) |
| `status` | VARCHAR(20) | NO | 'active' | Database status |

## 4. Constraints

### 4.1 Primary Key
- `id`: 16-character hex string (auto-generated)

### 4.2 Unique Constraints
- `slug`: URL-friendly identifier, unique across the current instance catalog when set; not project-scoped

### 4.3 Foreign Keys
- **None**: the existing schema has no foreign key to `auth_users`.
- Ownership is checked against the current instance caller in management methods. Admin-supplied owner IDs are not validated for account existence.
- Co-locating the tables does not change this schema contract or add a foreign key.

### 4.4 Check Constraints

**ID Format**
```sql
id ~ '^[0-9a-f]{16}$'
```
- 16 lowercase hex characters
- Auto-generated, never user-specified

**Slug Format**
```sql
slug IS NULL OR slug ~ '^[a-z][a-z0-9-]{2,62}$'
```
- Starts with lowercase letter
- Only lowercase letters, digits, and hyphens
- Length: 3-63 characters
- Optional (can be NULL)
- Immutable once set (enforced at application layer)
- Reserved slugs: `default`, `admin`, `system`, `api`, `auth` (enforced at application layer)

**Status Values**
```sql
status IN ('active', 'suspended', 'deleting')
```

**Non-negative Quotas**
```sql
max_documents >= 0
max_storage_bytes >= 0
```

## 6. Current Entity and Identifier Rules

```go
package database

import (
    "encoding/hex"
    "time"

    "github.com/google/uuid"
    "github.com/zeebo/blake3"
)

type Database struct {
    ID              string         `db:"id"`
    Slug            *string        `db:"slug"`
    DisplayName     string         `db:"display_name"`
    Description     *string        `db:"description"`
    OwnerID         string         `db:"owner_id"`
    CreatedAt       time.Time      `db:"created_at"`
    UpdatedAt       time.Time      `db:"updated_at"`
    MaxDocuments    int64          `db:"max_documents"`
    MaxStorageBytes int64          `db:"max_storage_bytes"`
    Status          DatabaseStatus `db:"status"`
}

type DatabaseStatus string

const (
    StatusActive    DatabaseStatus = "active"
    StatusSuspended DatabaseStatus = "suspended"
    StatusDeleting  DatabaseStatus = "deleting"
)

// GenerateID creates a new database ID using hex(blake3(uuid())[:8])
// Database IDs hash a random UUID; current user IDs hash the normalized username.
func GenerateID() string {
    u := uuid.New()
    hash := blake3.Sum256(u[:])
    return hex.EncodeToString(hash[:8])
}

// Reserved slugs that cannot be used by regular users
// Note: "default" is reserved for the system-created default database
var ReservedSlugs = map[string]bool{
    "default": true,  // System default database
    "admin":   true,
    "system":  true,
    "api":     true,
    "auth":    true,
}

// ValidateSlug checks if a slug is valid and not reserved
func ValidateSlug(slug string) error {
    if slug == "" {
        return nil // Empty is allowed (optional)
    }
    if ReservedSlugs[slug] {
        return ErrReservedSlug
    }
    // Regex validation: ^[a-z][a-z0-9-]{2,62}$
    if len(slug) < 3 || len(slug) > 63 {
        return ErrInvalidSlugLength
    }
    if slug[0] < 'a' || slug[0] > 'z' {
        return ErrInvalidSlugFormat
    }
    for _, c := range slug[1:] {
        if !((c >= 'a' && c <= 'z') || (c >= '0' && c <= '9') || c == '-') {
            return ErrInvalidSlugFormat
        }
    }
    return nil
}
```

## 7. Common Queries

### 7.1 Create Database

```sql
INSERT INTO databases (id, slug, display_name, description, owner_id, max_documents, max_storage_bytes, status)
VALUES ($1, $2, $3, $4, $5, $6, $7, 'active');
```

### 7.2 Get Database by ID

```sql
SELECT id, slug, display_name, description, owner_id, created_at, updated_at,
       max_documents, max_storage_bytes, status
FROM databases
WHERE id = $1;
```

### 7.3 Get Database by Slug

```sql
SELECT id, slug, display_name, description, owner_id, created_at, updated_at,
       max_documents, max_storage_bytes, status
FROM databases
WHERE slug = $1;
```

### 7.4 Resolve Identifier (for URL routing)

Used to resolve a URL path identifier to a database. The identifier can be:
- A slug (e.g., `my-app`)
- An ID with prefix (e.g., `id:a1b2c3d4e5f67890`)

```go
func (s *Store) ResolveIdentifier(ctx context.Context, identifier string) (*Database, error) {
    if strings.HasPrefix(identifier, "id:") {
        return s.GetByID(ctx, identifier[3:])
    }
    return s.GetBySlug(ctx, identifier)
}
```

### 7.5 List Databases by Owner

```sql
SELECT id, slug, display_name, description, owner_id, created_at, updated_at,
       max_documents, max_storage_bytes, status
FROM databases
WHERE owner_id = $1
ORDER BY created_at DESC, id
LIMIT $2 OFFSET $3;
```

### 7.6 Count Databases by Owner (Quota Check)

Note: `deleting` status databases count toward quota to prevent abuse.

```sql
SELECT COUNT(*) FROM databases
WHERE owner_id = $1;
```

### 7.7 Check Database Exists

```sql
SELECT EXISTS(
    SELECT 1 FROM databases
    WHERE id = $1
      AND status = 'active'
);
```

### 7.8 Update Database

The service loads and modifies the entity before updating. The Store preserves
an already-set slug and writes the remaining entity fields; `updated_at` comes
from the current Go call.

```sql
UPDATE databases
SET slug = CASE WHEN slug IS NULL THEN $2 ELSE slug END,
    display_name = $3,
    description = $4,
    status = $5,
    max_documents = $6,
    max_storage_bytes = $7,
    updated_at = $8
WHERE id = $1;
```

### 7.9 Delete Database (Soft)

```sql
UPDATE databases
SET status = 'deleting',
    updated_at = NOW()
WHERE id = $1;
```

### 7.10 Delete Database (Hard)

```sql
DELETE FROM databases WHERE id = $1;
```

### 7.11 List All Databases (Admin)

```sql
SELECT id, slug, display_name, description, owner_id, created_at, updated_at,
       max_documents, max_storage_bytes, status
FROM databases
WHERE ($1::VARCHAR IS NULL OR owner_id = $1)
  AND ($2::VARCHAR IS NULL OR status = $2)
ORDER BY created_at DESC, id
LIMIT $3 OFFSET $4;
```

### 7.12 Count All Databases (Admin)

```sql
SELECT COUNT(*) FROM databases
WHERE ($1::VARCHAR IS NULL OR owner_id = $1)
  AND ($2::VARCHAR IS NULL OR status = $2);
```

```sql
-- Existing catalog schema; this does not add project isolation

BEGIN;

CREATE TABLE IF NOT EXISTS databases (
    id VARCHAR(16) PRIMARY KEY,
    slug VARCHAR(63) UNIQUE,
    display_name VARCHAR(255) NOT NULL,
    description TEXT,
    owner_id VARCHAR(64) NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW(),
    max_documents BIGINT NOT NULL DEFAULT 0,
    max_storage_bytes BIGINT NOT NULL DEFAULT 0,
    status VARCHAR(20) NOT NULL DEFAULT 'active',

    -- Current schema has no foreign key or project binding
    CONSTRAINT chk_databases_id CHECK (
        id ~ '^[0-9a-f]{16}$'
    ),
    CONSTRAINT chk_databases_slug CHECK (
        slug IS NULL OR slug ~ '^[a-z][a-z0-9-]{2,62}$'
    ),
    CONSTRAINT chk_databases_status CHECK (
        status IN ('active', 'suspended', 'deleting')
    ),
    CONSTRAINT chk_databases_max_documents CHECK (max_documents >= 0),
    CONSTRAINT chk_databases_max_storage CHECK (max_storage_bytes >= 0)
);

CREATE INDEX IF NOT EXISTS idx_databases_owner ON databases(owner_id);
CREATE INDEX IF NOT EXISTS idx_databases_status ON databases(status);
CREATE INDEX IF NOT EXISTS idx_databases_created_at ON databases(created_at DESC);
CREATE INDEX IF NOT EXISTS idx_databases_slug ON databases(slug) WHERE slug IS NOT NULL;
CREATE INDEX IF NOT EXISTS idx_databases_owner_status ON databases(owner_id, status);

COMMIT;
```

Runtime schema initialization uses the same transaction-level advisory-lock
protocol as user schema initialization. The raw transaction example above is
not a substitute for that concurrent-startup protocol; see
[PostgreSQL initialization](../storage/06.user-store-postgres.md#7-schema-initialization).

The `default` slug is bootstrapped for the configured instance admin after
authentication initialization. Missing admin configuration/account can skip
bootstrap. See [bootstrap behavior](01.architecture.md#54-default-database-bootstrap).

## 9. Notes

### 9.1 Owner Validation
- There is no foreign key between `databases` and `auth_users`.
- Current management methods check caller ownership; they do not establish project/developer membership.
- The current factory shares their instance PostgreSQL connection. No global Console/Management catalog relocation is implied.

### 9.2 Default Database
- Created by instance bootstrap with slug `default` when its prerequisites exist
- Owned by the configured instance admin user
- Cannot be deleted (protected)

### 9.3 Slug Immutability
- Slug can be set at creation or added later via update
- Once set, slug cannot be changed (enforced at application layer)
- Hard-deleted catalog rows release their slug; cleanup and namespace limitations are documented in [lifecycle](05.lifecycle.md)

### 9.4 Quota Counting
- All rows (including `deleting`) count toward the current instance-user creation limit; project/developer quotas are not defined
- This prevents abuse via rapid create/delete cycles

### 9.5 Soft Delete
- Deletion sets `status = 'deleting'`; the current worker performs cleanup.
- Current document deletion failures retain the row for retry, but Indexer invalidation errors are logged and do not prevent metadata hard deletion.
- The target requires successful required document and index cleanup before catalog removal and slug release; failures retain the deleting row and reservation. See [lifecycle completion requirements](05.lifecycle.md#7-accepted-target-and-open-lifecycle-decisions).

### 9.6 Performance Considerations
- Slug lookups use `idx_databases_slug` (partial index)
- Owner queries use `idx_databases_owner`
- Quota checks are simple COUNT (includes all statuses)
- Existence checks hit primary key

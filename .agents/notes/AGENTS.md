# Agent Notes Instructions

Read [README.md](README.md) for the directory layout, English section names,
lifecycle, and retention rules. Notes record durable rationale and consequences.
Local execution plans remain in the gitignored `docs/plans/` directory, existing
task reports retain validation history, and design discussions retain Why
alongside How.

Before creating a note, search for an existing owner. Update it for the same
decision; write and cross-link a new note when the decision changes. Preserve
the historical reason for the earlier choice while synchronizing current facts.

Archived notes are immutable. New decisions may reference them without editing
their contents or repairing their historical links.

Use [agent-notes](../skills/agent-notes/SKILL.md) for the workflow,
[scope-cut](../skills/scope-cut/SKILL.md) for actual scope decisions, and
[prose-standard](../skills/prose-standard/SKILL.md) for writing and review.
The authorized task determines whether to analyze or edit.
